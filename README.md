# Full Stack Application

This project is a comprehensive full stack application built with React for the frontend and Node.jswith Express for the backend. It comprises two frontend components: the admin-frontend and the user-frontend, designed for organizational tidiness.

Admin Frontend: Manages horse vaccination, trimming, and worming records.

User Frontend: Delivers a responsive design detailing information about DD Cattle Company and provides information about the animals on the ranch.

## Project Structure

```

├── server          # Backend application

│   ├── package.json # NPM configuration for the backend
│   ├── tsconfig.json # TypeScript configuration for the backend
│   └── README.md    # Documentation for the backend
├── frontend         # Frontend application
│   ├── src         # Source files for the frontend
│   ├── package.json # NPM configuration for the frontend

|__ admin-frontend #Administative tools for the website

└── README.md        # Documentation for the entire project
```
